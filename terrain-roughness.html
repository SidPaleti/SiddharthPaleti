Can a centipede robot feel how rough the ground is?

Can simulation data of a centipede be used to estimate terrain roughness? I reduced the simulation data with PCA and tested eleven regression models. PLS regression explained 80% of the variation in terrain roughness.

Researcher Siddharth Paleti Lab Locomotion in Biology and Robotics (LIBR) Lab Advisor Dr. Baxi Chong Project Terrain roughness estimation · Spring 2026 Data 96 centipede simulation runs Software MATLAB
Introduction Reducing the data Analyzing the data Conclusion

Introduction

The centipede robot can currently move and traverse flat terrain. The next step is being able to move through different terrain roughness. To traverse rough terrain, the robot needs to identify how rough the terrain is so it knows how to move through it.

We can't hard-code the robot to move through the terrain because the roughness is unknown, but the motors on the robot can receive signals such as torque, velocity, acceleration and other factors. By creating a simulation of a centipede in a 3D space, we can simulate data of the joints and parameters, such as link position, link velocity, joint torque, contact force and many others, to represent how the centipede reacts in different terrains.

In this project, the simulation data is used to determine whether the parameters and links of the centipede can be used to predict terrain roughness.

Reducing the data

Once the data was obtained from the simulation, the analysis required ninety-six files, fifty-three parameters for each file, and 60 to 176 joints for each parameter. Each file correlates to a simulation run on a certain terrain roughness. The simulation had four distinct types of terrain: Terrain 0.0, Terrain 0.7, Terrain 1.4 and Terrain 2.0.

The simulation gave around 600,000 data points. That is too much to analyze, because not only is the size of the problem large, the variation within the data is similar and much of it may be redundant.

Once I extracted the data from the simulation files, I ran Principal Component Analysis (PCA), a dimensionality reduction technique, to find the dominant components of variation. PCA works best for a 2-dimensional matrix, and this matrix was 4-dimensional. I converted the features, parameters and links to be associated with the columns, and the rows correlated to the files, the terrain roughness.

The PCA reduced the parameters to twenty-two principal components and the links to thirty-seven principal components, creating a 96 × 815 table.

  • 96 simulation files
  • 4 terrain types: 0.0, 0.7, 1.4, 2.0
  • 53 parameters per file
  • 60 to 176 joints per parameter
  • ~600,000 data points
  • PCA: 22 parameter PCs, 37 link PCs
  • 96 × 815 table

Analyzing the data

After reducing the simulation data with PCA, the new table is analyzed using regression models to predict terrain roughness. The models tested were ridge regression, lasso, elastic net, PCA with linear regression, PLS regression, linear SVR, Gaussian SVR, Gaussian kernel ridge, Gaussian process regression, random forest and gradient boosting. The reason for testing so many models was to determine which type of regression model best represented the relationship between the PCA table and the terrain roughness.

In Figure 1, the plots represent the regression models and compare the predicted roughness values (the blue points) against the actual roughness values. The red dashed line is the perfect scenario, where predicted roughness equals actual roughness. The closer the predicted values are to the red dashed line, the more promise that model shows for predicting the terrain.

The values shown in Figure 1, sorted by RMSE.

The graphs use root mean square error (RMSE) to measure the error between the predicted and actual roughness, so ideally this value is as small as possible. They also use R2, which ranges from 0 to 1 and indicates how well the data fits the regression model, with a value close to one suggesting better predictive accuracy.

From these values, ridge regression, PLS regression, linear SVR and Gaussian kernel ridge performed the best overall, since their predictions stayed closest to the red dashed line. Ridge regression had an RMSE of 0.350 and an R2 of 0.801. PLS regression had an RMSE of 0.351 and an R2 of 0.800. Linear SVR had an RMSE of 0.371 and an R2 of 0.777, and Gaussian kernel ridge performed similarly with an RMSE of 0.362 and an R2 of 0.787.

Figure 2 shows the PLS regression model with the actual roughness values and the predicted roughness values plotted on the same axis. The graph shows how the predicted values follow the general trend from low roughness to high roughness.

The lower and middle roughness regions match the actual values well, with some errors. The predicted values for roughness 2.0 are slightly below the correct value. The model is still able to capture the increase, but it is reducing some of the higher roughness values.

Conclusion

The goal of this project was to determine whether simulation data of a centipede could be used to estimate terrain roughness. The results showed that a PLS regression model was able to explain 80% of the variation in the terrain roughness, and the predicted vs. actual graph also showed that the model was able to follow the trend of the actual terrain roughness.

The model is not perfect, and its predictions are rarely the same as the actual data. Future work will use more simulations of a terrain that represents the one that will be used in the Locomotion Robotics Lab.
