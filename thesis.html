Honors thesis

Style vs. User

Separating how a person writes from what they are writing, so that a writer's style can be measured and redrawn on top of a generic trajectory.

Student Siddharth Paleti Advisor Dr. Katie Fitzsimons Lab Human-Centered Robotics Lab Program Schreyer Honors College, Penn State Status In progress · last update Oct 27, 2026
The question Method Results Timeline Next steps

The question

Every handwritten character is a trajectory: the path a pen traces through time. What you see in a recorded "S" depends on two things at once, the task (which character is being written) and the user (who is writing it).

The objective of this thesis is to represent handwriting trajectories by separating the style from the task. If that works, a writer's style becomes a quantity you can measure, compare across tasks, and apply to a generic trajectory to produce a personalized one.

In short: find the directions in which handwriting varies, test which ones belong to the writer and which to the character, then use the writer's directions to redraw their style.

Method

Four stages, from raw pen paths to a redrawn, personalized trajectory.

Represent each trajectory as a ProMP

A probabilistic movement primitive describes a trajectory as a weighted sum of basis functions, yt = φtTw + ε, with a Gaussian distribution over the weights. Time is normalized to [0, 1] so every sample, whatever its length, becomes a weight vector of the same size.

Trajectory model \[ y_t = \phi_t^{\top} w + \epsilon_y \qquad p(w) = \mathcal{N}\!\left(w \mid \mu_w, \Sigma_w\right) \]
Fixed-length vectors \[ z_t = \frac{t - t_0}{t_1 - t_0} \qquad y_{t_{norm}} = \phi_{z_t}^{\top} w + \epsilon_y \qquad w \in \mathbb{R}^{KD} \]

Find the main directions of variation with kernel PCA

An RBF kernel measures how similar two weight vectors are. Solving the eigenproblem on the kernel matrix gives principal components, and each trajectory gets a score on every component.

Kernel, eigenproblem, score \[ k(x_i, x_j) = \exp\!\left(-\frac{\lVert x_i - x_j \rVert^{2}}{2\sigma^{2}}\right) \qquad \ell\lambda\alpha = K\alpha \qquad z_k = \sum_{n=1}^{\ell} \alpha_n^{k}\, k(x_n, x) \]

Test which components track the user and which track the task

For every principal component, an ANOVA asks whether its scores differ by writer, by character, by both, or by neither. That sorts the components into user-dominated, task-dominated, shared and noise. See the results below.

Decode the style with ridge regression and redraw

Ridge regression (α = 1) learns a map from scores back to ProMP weights. A writer's style is the offset between their average position in score space and the population average. Decoding that offset gives a weight change Δw that is added, with a style gain g, to the task's mean weights.

Ridge decoder \[ \hat{B} = \left(Z^{\top} Z + \alpha I\right)^{-1} Z^{\top} W \qquad \hat{w}(z) = \hat{B}^{\top} z + b \]
Styled point and weight offset \[ z_{style} = z_{ref} + \left(\bar{z}_u - \bar{z}_{pop}\right) \qquad \Delta w = \hat{w}(z_{style}) - \hat{w}(z_{ref}) \]
Personalized vs. generic trajectory \[ w_{pers} = \mu_{task} + g\,\Delta w \] \[ y_{pers}(t) = s\,\big(\phi(t)\,w_{pers}\big) + m \qquad y_{generic}(t) = s\,\big(\phi(t)\,\mu_{task}\big) + m \]

Here s and m are a scale and an offset, and g is the style gain (g = 1 in the figures below).

Results so far

The pipeline runs end to end: ANOVA finds components that belong to the writer, and decoding them changes the redrawn trajectory.

Reading the scatter

The scores spread out along two axes in a cross shape rather than a round cloud, so trajectories vary strongly along each of these components. That makes them candidates for describing a writer's style.

    Objective sharpened, style redrawn for User 1
